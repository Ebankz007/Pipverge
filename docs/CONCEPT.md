# Pipverge — Concept

> Working document. Grows only from Henry's frame and verified fact.
> Last updated: 2026-10-11.

## 1. One-line frame

**Pipverge is a trading-intelligence brand — a marketing site and content-managed CMS for a
forex/gold/index signal service and EA (Expert Advisor) shop — built to the structure and user
experience of the reference site `tradeiq.tech`, rebranded and restyled gold/black, with a
net-new database, secure auth, and admin CMS behind it.**

## 2. What it is

- **Public face:** a modern fintech marketing site — Home, About, Features, Services, Pricing, FAQ,
  Contact, Login/Register, and legal pages — presenting signal plans and EA products.
- **Engine room:** a full admin CMS on PostgreSQL so a non-developer can edit every meaningful
  word, price, plan, testimonial, FAQ, menu item, page, and setting — with Draft → Preview →
  Publish.
- **Voice:** *Intelligent trading. Smarter decisions. Better execution.* Professional, precise,
  no hype, no guaranteed-return claims.

## 3. Who it serves

- **Retail traders** wanting structured signals / EAs.
- **Introducing brokers / referrers** (mirrors the reference's IB / refer-and-earn roles).
- **The operator (Pipverge)** who needs to run the whole site from an admin console.

## 4. The wedge

The reference is a **mock** — no backend, test-mode payments, placeholder legal pages. Pipverge's
wedge is that it is the **real, operable version**: a genuine CMS, real database, real auth, real
content pipeline. Same polish, actual substance.

## 5. Displacement

Displaces the "Lovable one-pager" class of fintech landing site: pretty but unmaintainable and
un-operable. Pipverge keeps the polish and adds the operational spine.

## 6. Business model

- Recurring **signal subscriptions** (Standard / VIP).
- One-time **EA licenses**.
- **Broker referral** partnerships (CMS-driven, disclaimed).

## 7. Risks & compliance posture

- **Financial-promotion risk.** Performance figures must be sample/illustrative, disclaimed, and
  CMS-controlled — never presented as guaranteed or "verified" without a real verified account.
- **Referral/affiliate risk.** Broker promo clearly labelled as a referral offer with a risk note.
- **Legal pages** shipped with reviewable baseline copy (flagged for counsel), not fake sign-off.

## 8. Kill criteria

- If the performance-claims question cannot be answered honestly (no real verified data and no
  willingness to label it sample), ship the section without fabricated numbers.
